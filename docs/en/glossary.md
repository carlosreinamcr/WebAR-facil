# Glossary

| Term | Definition |
| --- | --- |
| Anchor | Stored transform used to keep virtual content at a placement. |
| Chroma key | Technique that removes a selected background color from video. |
| Descriptor | Compact representation of a local image feature for matching. |
| Drift | Accumulated spatial pose error over time. |
| GLB | Binary glTF container for 3D assets. |
| Hit test | Query for a surface intersection from a ray in an XR session. |
| Keyframe | Selected frame whose features and pose help describe a local map. |
| Optical flow | Estimated movement of image points between frames. |
| Parallax | Relative image motion caused by changing viewpoint. |
| Pose | Position and orientation in a reference coordinate system. |
| Redetection | Searching for a known image again when tracking needs recovery. |
| Relocalization | Recovering a camera pose relative to a previously observed map. |
| SLAM | Simultaneous localization and mapping. |
| WASM | WebAssembly, used for computational workloads in the vision workers. |
| WebXR | Browser API for immersive XR sessions on supported devices. |
