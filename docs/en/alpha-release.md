# Preparing the public alpha

Before distributing a GitHub archive or updating the hosted bundle, verify it from a clean extraction. Include the MIT license, dependency notices, source, lockfile, documentation and runnable examples. Keep development reports, environment settings and installed dependencies out of the archive.

- Build and run the documentation checks from the extracted copy.
- Start with the declarative marker example, then test video and spatial placement.
- Check that the English and Spanish manuals contain the same chapters and link to each other.
- Record results separately for desktop, iOS and Android. Record backend and browser for spatial tests.
- Keep experimental markerless metric placement visibly identified in its example.

See [contributing](contributing.md) for commands and [device validation](device-validation.md) for acceptance scenarios.
