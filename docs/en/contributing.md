# Development, tests and contributions

Install the Node.js version specified by the repository and restore the locked dependencies with `npm ci`. Run the checks relevant to the change from the repository root.

```sh
npm run check
npm test
npm run build
npm run docs:check
npm run test:browser
```

For tracking changes, report the device, browser, backend, performance preset and test scene. Compare acquisition, steady tracking and recovery independently. For public API changes, update the examples, both manuals, and the declaration-derived reference in the same change. See [implementation verification](verification.md) and [physical-device acceptance](device-validation.md).
