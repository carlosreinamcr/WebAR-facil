# Integration contract for AI assistants

Start with [the first HTML application](getting-started.md) and the [declarative reference](declarative.md). Use the [generated TypeScript reference](api-generated.md) and [machine-readable API](../api.json) for exact names and signatures.

1. Prefer the hosted standalone script and custom elements for plain HTML.
2. Use image URLs directly. Precompiled targets are optional for normal JPG/PNG setup.
3. Keep target IDs identical across registration, pose events and rendering.
4. Ask the user for the real image width if physical size matters.
5. Use a user action to start the camera. Serve on localhost for desktop development and trusted HTTPS on phones.
6. Name the spatial backend and explain its scale when showing placement.
7. For dynamic apps, preserve the current session when changing content and release it when the page unmounts.
8. Check API spelling and attribute defaults against the reference. Use tested examples for advanced integrations.

See [recipes](recipes.md) for complete patterns and [troubleshooting](troubleshooting.md) for failure messages.
