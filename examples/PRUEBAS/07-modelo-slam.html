07. Modelo GLB con SLAM óptico

Cómo desarrollar este ejemplo

Modelo original incluido: un robot ligero. Cambia únicamente la ruta de src para utilizar tu GLB. En odometría la escala es relativa: ajusta size/width si el contenido queda pequeño.

Mueve lentamente el teléfono sobre una zona con textura. Cuando aparezca la cuadrícula, pulsa «Colocar aquí». La escala óptica es relativa.

Pulsa «Iniciar AR» en la escena.

Cargando SDK… Si este texto permanece, revisa la ruta del script y que hayas ejecutado npm run build.
