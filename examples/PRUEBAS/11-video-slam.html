11. Vídeo MP4 con SLAM

Cómo desarrollar este ejemplo

El vídeo aparece como contenido AR. El recurso incluido muestra una figura roja sobre verde; puedes activar chroma añadiendo el atributo indicado en el código. En odometría la escala es relativa: ajusta size/width si el contenido queda pequeño.

Mueve lentamente el teléfono sobre una zona con textura. Cuando aparezca el anillo, pulsa «Colocar aquí». La escala óptica es relativa.

Pulsa «Iniciar AR» en la escena.

Cargando SDK… Si este texto permanece, revisa la ruta del script y que hayas ejecutado npm run build.
