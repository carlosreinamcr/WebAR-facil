# Phone detector / Detector de celulares

Optional example using TensorFlow.js 4.22.0, COCO-SSD 2.2.3 and the official SSD Lite MobileNet V2 graph and weights. Inference runs in a dedicated worker. These assets are local and only loaded by example 31. The model detects the COCO category `cell phone` and gives a 2D box and a confidence score.

Ejemplo opcional con TensorFlow.js 4.22.0, COCO-SSD 2.2.3 y el modelo oficial SSD Lite MobileNet V2. El Worker procesa la cámara localmente. La detección proporciona un rectángulo 2D y confianza. La escena coloca el GLB en pantalla a partir de ese rectángulo.

- Runtime: https://github.com/tensorflow/tfjs
- Detector: https://github.com/tensorflow/tfjs-models/tree/master/coco-ssd
- Model: https://storage.googleapis.com/tfjs-models/savedmodel/ssdlite_mobilenet_v2/model.json
