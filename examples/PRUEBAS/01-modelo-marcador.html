01. Modelo GLB con marcador

Cómo desarrollar este ejemplo

Modelo original incluido: un robot ligero. Cambia únicamente la ruta de src para utilizar tu GLB.

Abrir marcador · Pulsa «Iniciar AR» y apunta a la imagen del marcador, mostrada en otra pantalla o impresa.

Pulsa «Iniciar AR» en la escena.

Cargando SDK… Si este texto permanece, revisa la ruta del script y que hayas ejecutado npm run build.
